# Phase 4 – Wireframes

Ce dossier contient les wireframes basse fidélité de l’application.

Les wireframes représentent la structure générale des écrans sans
détails graphiques. Ils servent à :
- définir l’architecture de l’information
- organiser les contenus
- valider les parcours utilisateurs avant le design final

Ces wireframes couvrent les écrans principaux du MVP.
