
# Phase 2 – Personas

Ce dossier présente les personas définis à partir de la phase de
recherche.

Les personas représentent des utilisateurs types de l’application.
Ils permettent de guider les décisions de conception en gardant en
tête des objectifs, motivations et frustrations réelles.

Chaque persona est directement issu des interviews et observations
réalisées lors de la phase de recherche.
