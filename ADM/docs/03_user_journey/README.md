# Phase 3 – User Journey

Ce dossier décrit le parcours utilisateur principal de l’application.

Le user journey permet de visualiser, étape par étape, l’expérience
d’un utilisateur depuis son arrivée sur la plateforme jusqu’à sa
participation à un débat.

Il met également en évidence :
- les points de friction
- les opportunités d’amélioration de l’expérience
