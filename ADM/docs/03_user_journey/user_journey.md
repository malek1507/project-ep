# User Journey – Participation à un débat

1. Arrivée sur l’application
2. Connexion ou inscription
3. Consultation des thèmes
4. Sélection d’un débat
5. Lecture des arguments existants
6. Choix d’une position
7. Publication d’un argument
8. Réactions aux autres arguments

## Points de friction
- Compréhension initiale
- Crainte de s’exprimer

## Opportunités
- Messages explicatifs
- Règles visibles
