# Phase 8 – Priorisation et définition du MVP

Ce dossier présente la priorisation des fonctionnalités et la définition
précise du périmètre du MVP.

Il permet de justifier :
- les choix fonctionnels
- les fonctionnalités incluses
- celles volontairement exclues

Cette étape est essentielle pour cadrer la phase de développement.
