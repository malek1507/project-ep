# Définition du MVP

## User Flow principal
Connexion → choix d’un thème → débat → publication d’un argument

## Écrans essentiels
- Accueil
- Liste des débats
- Page débat
- Création de débat

## Fonctionnalités incluses
- Comptes
- Débats
- Arguments

## Exclusions
- Chat privé
- Notifications
- Recommandations
